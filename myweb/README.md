# Parsa Portfolio

A component-based React + Tailwind CSS portfolio for Parsa.

## Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- Lucide React

## Structure

```text
src/
├── components/
│   ├── layout/
│   ├── sections/
│   └── ui/
├── context/
├── data/
├── hooks/
├── styles/
├── App.jsx
└── main.jsx
```

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Where to edit your content

- `src/data/profile.js` — personal links/contact
- `src/data/projects.js` — projects
- `src/data/skills.js` — skill grouping

No backend is required.
